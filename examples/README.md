# Synthetic examples

This directory is reserved for deliberately generated demonstrations and fixtures. No datasets are included yet.

For each future example, document how it was generated, the expected result, and the tool version used. Use reserved example identifiers and fictional data. Redaction alone is not a guarantee that real evidence is safe to publish.

Do not commit real disk images, memory dumps, packet captures, event logs, browser profiles, credentials, or personal data. Keep real case work outside the repository.
